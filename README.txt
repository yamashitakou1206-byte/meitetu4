MEITETSU Operation Web v5.0

今回のv5では、名古屋鉄道の公式「路線別時刻表」PDFを自動取得・解析し、列車番号から列車詳細画面を表示する仕組みを追加しています。

■ 使い方
1. このフォルダの中身をGitHub Pagesのリポジトリrootへアップロード。
2. GitHubのActions → 「名鉄公式時刻表データ更新」を開く。
3. 「Run workflow」を実行。
4. Actionsが名鉄公式の路線別時刻表ページからPDFを取得し、data/timetables.jsonを生成します。
5. 生成後、GitHub Pagesを再読み込みします。

■ 自動更新
毎週月曜日のUTC 03:17にも自動実行します。名鉄側でPDFが更新された場合も次回実行時に再取得します。

■ 列車番号検索
例：1980、1981、1996、2082F など。実際に公式PDFに掲載されている列車番号は、平日／土・休日と方向を考慮して検索します。
検索結果はスクリーンショット風の列車詳細画面へ遷移します。

■ 重要
・時刻表のPDFは名古屋鉄道公式サイトから取得します。
・PDFの解析は自動処理なので、複雑な乗継・併結・通過記号などは完全に再現できない場合があります。
・名鉄公式ページには、秒を切り捨てて掲載すること、臨時列車等が掲載されない場合があることなどの注意書きがあります。
・運行情報や列車走行位置はこのアプリの別機能であり、公式リアルタイムデータとは別です。


【v5.1 乗務区表示】
列車詳細画面の上部に表示する乗務区を、列車の路線に応じて切り替えるようにしました。
名古屋本線・豊川線・津島線・尾西線・竹鼻線・羽島線 → 名古屋乗務区
常滑線・空港線・河和線・知多新線 → 神宮前乗務区
犬山線・各務原線・広見線・小牧線 → 犬山乗務区
三河線・豊田線・西尾線・蒲郡線 → 知立乗務区
瀬戸線 → 瀬戸運輸区

※上記は路線単位の主な担当区を表示する設定です。実際の列車では直通運転や交代などにより担当が異なる場合があります。
